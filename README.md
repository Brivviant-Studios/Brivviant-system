# Brivviant Studio — V12 Project Workflow

This package keeps the original FINAL V10 static runtime intact and adds V12 behavior through additive patch files. Upload the package contents to the GitHub Pages repository root; no npm build is required for the ready static deployment.

V12 adds staged project workflows with planned hours, project-level scoring, preserved delivered-task history, leave/request escalation and rejection reasons, approval audit, Gemini voice task creation with model failover, bilingual AR/EN UI controls, highlighted unread notifications, and Web Push support.

The V12 migrations and Edge Functions were already applied/deployed to the current Studio Supabase project on October 1, 2026. Keep Gemini and server secrets in Supabase, never in GitHub.
