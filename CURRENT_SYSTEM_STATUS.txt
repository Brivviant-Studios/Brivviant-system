BRIVVIANT STUDIO — V12 PROJECT WORKFLOW STATUS

RUNTIME / UI
- The live interface is still the original FINAL V10 static bundle.
- index.html still loads assets/index-BRIVVIANT-FINAL-V10.js and .css unchanged.
- V12 is additive through v11-patch.js + v11-patch.css, plus sw.js / manifest.webmanifest.
- No React/Vite rebuild is required to deploy the ready static site.

V12 WORKFLOW
- First-time leave requests are valid and saved directly.
- Rejected requests display the rejection reason to the requester.
- Repeated rejected requests are escalated; Team Leader cannot reject the escalated attempt again.
- Moving a task to Delivered archives it; history, time, submissions, audit and points remain stored.
- Projects can be planned as staged workflow with assignee + planned hours per stage:
  Brief Review -> Direction -> Modeling/Elements -> Rendering -> Finalization -> Delivery.
- Stages run sequentially with individual submission / approval gates.
- Task Owner, final approver, approval note, revisions and quality flags are retained in approval audit.

POINTS
- Normal submission no longer awards points by itself.
- Project points are posted on final project approval, based on actual stage hours vs planned hours.
- Self-caused error revision or negligent pause makes that user's score for the project 0.
- Management can add/deduct manual points with a mandatory reason.
- Point ledger is independent from task archive/deletion state.

VOICE
- Live Edge Function: brivviant-voice-task.
- GEMINI_API_KEY stays in Supabase Edge Function Secrets only.
- It rotates through a Gemini model pool and falls back to the normal/manual task flow when AI is unavailable.

NOTIFICATIONS
- Unread notifications are strongly highlighted in the UI.
- Web Push is supported through brivviant-push + sw.js.
- A user must grant browser/OS notification permission once; browsers do not allow sites to bypass this permission.
- On supported mobile browsers/PWA installs, notifications can arrive while the site is not open.

LANGUAGE
- AR / EN control is added to the top bar.
- Main workspace terminology and headings use professional project-operations copy.

SUPABASE

- database/20261001_v12_project_workflow.sql is retained for source control / fresh environments.
