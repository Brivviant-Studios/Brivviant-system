# Brivviant Studio V6.1 — نسخة جاهزة للرفع

## مهم: هذه هي الواجهة الجديدة
رقم V6.1 ظاهر أسفل صفحة الدخول وداخل مساحة الفريق.
ملف index.html ومجلد assets في جذر الحزمة هما النسخة الجاهزة للتشغيل؛ مجلد source يحتوي الكود القابل للتعديل.
لا ترفع مجلد source وحده ولا تنقل محتواه فوق ملفات الجذر.

## تحديث GitHub Pages
1. فك الضغط وارفع محتويات Brivviant_Studio_V6_1 إلى جذر المستودع المستخدم للموقع.
2. استبدل index.html القديم، وارفع assets وbrivviant-logo.png وfavicon.svg وsw.js و.nojekyll معًا.
3. إعداد Pages: النشر من الفرع main، المجلد / (root)، أو نفس الفرع الذي تستخدمه بالفعل.
4. انتظر اكتمال النشر في GitHub ثم افتح رابط الموقع مع ?v=6.1 واضغط Ctrl+Shift+R.
5. تأكد من ظهور V6.1. لو لم يظهر فأنت تفتح رابطًا آخر أو أن النشر لم يكتمل. رابط صفحة المستودع ليس رابط الموقع.

الملفات الجاهزة لا تحتاج npm أو عملية Build لرفعها على GitHub Pages. أسماء ملفات JS وCSS تحتوي بصمة الإصدار لتجنب استخدام ملفات الواجهة القديمة من الكاش. لا تحذف بيانات Supabase عند تحديث الواجهة.

## ما تم تنفيذه
- حسابات مستقلة باسم مستخدم وكلمة مرور؛ الحسابات الموجودة وكلمات مرورها لم تتغير.
- CEO: Mohamed Zidan، Mohamed Farouk، Seif Akram. EMY تضيف التاسكات؛ التوزيع للـCEO فقط.
- أي عضو مفعّل يمكن أن يستلم تاسك، بما فيهم CEO وEMY، سواء منفردًا أو مع أعضاء آخرين.
- البريف ورابط Drive وموعد التسليم إجباريون.
- كل عضو يبدأ تكليفه بنفسه. إيقاف واستكمال التايمر للـCEO فقط.
- الوقت محفوظ من الخادم ولا يعتمد على بقاء صفحة الموظف مفتوحة.
- الاعتماد وطلب التعديلات للـCEO فقط، والتعديل له موعد جديد وسجل الجولات محفوظ.
- التأخير عند التسليم يحتاج سببًا.
- الطلبات والشكاوى محفوظة مع حالة التنفيذ ورد الإدارة، وخصوصيتها لصاحبها والـCEO.
- محادثات خاصة بين أي عضوين؛ لا يستطيع CEO ثالث قراءتها من النظام.
- الرسائل وحالة قراءتها محفوظة في Supabase. إعادة إرسال نفس الطلب بعد فشل الشبكة لا تكرر الرسالة.
- إشعارات داخل الموقع لجميع الأعضاء المفعّلين عن تحديثات التاسكات والفريق؛ تفاصيل التاسك تظهر للمسموح لهم فقط.
- إشعارات الرسائل الخاصة لمستلمها، وإشعارات الشكاوى لصاحبها والإدارة فقط.
- عداد إشعارات غير مقروءة، وتحديد كمقروء، وتحميل الرسائل والإشعارات القديمة.
- حذف أي تاسك للـCEO بعد التأكيد. الحذف يؤرشفه في Supabase ويوقف مؤقّتاته ويحفظ التسليمات والسجل.

## حدود التنبيهات
التنبيهات لحظية داخل الموقع أثناء فتحه. إن كان الموقع مغلقًا، تُحفظ الإشعارات وتظهر عند العودة. هذه النسخة لا ترسل Push للهاتف أو تنبيهات سطح المكتب أثناء إغلاق الموقع.

## تعديل الكود
الكود في source. يتطلب Node.js >=22.13 وpnpm 11.25.0.
```sh
cd source
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```
لإنشاء ملفات جاهزة بعد أي تعديل:
```sh
pnpm build
```
ارفع محتويات source/dist إلى جذر الموقع. لا ترفع node_modules أو مفاتيح خدمة Supabase.
